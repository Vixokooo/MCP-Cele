# MCP Academic Organizer (`mcp-academic-organizer`)

Servidor **Model Context Protocol (MCP)** desarrollado en TypeScript a partir de `mcp-starter-kit`, diseñado para conectar **opencode** (y otros clientes MCP) con el sistema de archivos local del estudiante. Permite auditar carpetas de estudio, buscar conceptos clave dentro de apuntes de clase y generar guías de estudio estructuradas por asignatura directamente en el disco local.

## Requisitos

- **Node.js**: v18.0.0 o superior.
- **npm**: v9.0.0 o superior.
- **opencode** (incluido o instalable automáticamente mediante `Iniciar.bat` / `Iniciar.command` del kit).
